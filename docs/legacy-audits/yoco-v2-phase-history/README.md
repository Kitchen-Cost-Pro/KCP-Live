# Historical Yoco V2 phase records

These files are retained as immutable migration and audit history. They describe earlier shadow, pilot, controlled-cutover, rollback, and legacy-shutdown phases.

They are not current operating instructions and must not be used to configure the final V2-only runtime. Current architecture, deployment, reconciliation, reporting, and support guidance is listed in `docs/yoco-v2/README.md` and the final release audit documents in `docs/`.
